# 🔐 Password Manager

A simple and responsive **Password Manager** built using React.js.  
The application allows users to add, view, edit, delete, and copy saved passwords through a simple and user-friendly interface.

This repository contains two versions of the project: one using **Browser Local Storage** and another using **MongoDB with a Node.js and Express.js backend**.

## 🚀 Features

- Add and save passwords
- View saved passwords
- Edit existing passwords
- Delete passwords
- Copy passwords to clipboard
- Simple and responsive UI
- Local Storage implementation
- MongoDB database implementation
- REST API integration
